# Как добавить API в шлюз

Новое API — пакет `services/gateway/src/main/java/org/mytpu/gateway/integrations/<id>/`: бин `Integration` и инструменты `Tool`
(образец — `integrations/example`). Ядро шлюза не трогается. Подключение без кода (коннекторы) — раздел «Коннектор из консоли» ниже.

## Ответ инструмента
- `summary` — готовая фраза на русском; `data` — запись (record) для карточки; `hint` — что делать дальше (`docs/LLM.md`, раздел 2).
- Описание, подсказки к аргументам и `title` — в `src/main/resources/tools/descriptions.properties`, не в коде.

## Личные данные (specs/personal-data-for-agents)
Если инструмент отдаёт личное (`ToolDescriptor...sensitivity(Sensitivity.PERSONAL)` или `SENSITIVE`):
1. **Каждое поле ответа** — с пометкой `@Classified(value = …, mask = …)`, включая вложенные записи и элементы списков.
   Без пометки шлюз не стартует и назовёт инструмент и поле.
   - `PUBLIC` — можно всем (название школы, номер аудитории);
   - `PERSONAL` + маска: `HIDE` (убрать), `INITIALS` (ФИО → «И. И. И.»), `COUNT` (список → сколько), `COARSE` (дата → месяц);
   - `SENSITIVE` — оценки, заявления, почта, медицинское: внешний агент их не получает никогда.
2. **Безопасная фраза**: `ToolAnswer.personal(summary, publicSummary, data)`. `publicSummary` — та же мысль без ПД
   («3 дедлайна, ближайший — через 2 дня»). Без неё внешний агент получит общую фразу «Ответ показан в «Мой ТПУ»».
3. **Варианты выбора** (`needs_choice`) — без ПД: группа, курс, номер заявки, а не ФИО. Шлюз не маскирует отдельные
   варианты: в режиме `full` они уходят как есть (обрезаются до `maxItems` и остатка суточного лимита), в остальных
   режимах весь выбор заменяется фразой `personal.choice_in_app` («пользователь выберет вариант в «Мой ТПУ»»).
4. Списки длиннее `maxItems` (по умолчанию 20) или остатка суточного лимита шлюз обрежет сам и допишет «показано N из M».
5. Вызов личного инструмента без пользователя (мастер-ключ без входа ТПУ) шлюз не допустит; проверить режимы на dev-стенде —
   заголовки `X-Dev-*` (`services/gateway/README.md`).

## Коннектор из консоли (без кода, specs/console-and-connectors, шаг 10)
Открытое HTTP API с JSON-ответом подключается экранами консоли «Коннекторы»; шлюз не пересобирается.
1. **Новый коннектор** → id (`a-z0-9_`), название, адрес API (только `https://`, не адрес внутренней сети), способ входа:
   нет / ключ в заголовке / ключ в параметре / логин и пароль / OAuth2 client_credentials (адрес токена — `https://`).
2. **Разрешение (scope)** — имя вида `holidays.read`, название и описание: его потом добавляют ключам. Имена scope и
   инструментов не должны совпадать с чужими.
3. **Инструменты:** имя (`a-z0-9_`), описание для модели, путь от адреса API (`/PublicHolidays/{year}/RU`), параметры
   (каждый `{параметр}` пути — в списке с «в пути»; параметры запроса — тип, обязательность, значение по умолчанию,
   список значений), ответ — JSON Pointer до объекта или списка, режим «объект / список / значения словаря», поля
   (имя → pointer внутри элемента → подпись), не больше N элементов, фраза `summary`. Ошибки — у поля до отправки.
4. **Сохранить версию** — черновик; шлюз ещё раз проверяет описание и отвечает списком ошибок по-русски.
5. **Секреты** (если вход с ключом) — вводятся на странице коннектора, хранятся зашифрованными в шлюзе и привязаны к
   адресу API и способу входа: после смены адреса секрет вводят заново. Значение не возвращается ни одним ответом.
6. **Проверить** — вызов выбранного инструмента с аргументами: итог, данные и сырой ответ (вызов пишется в журнал
   действий).
7. **Опубликовать** — окно с отличиями от опубликованной версии; через ≤ 30 с инструмент виден в `tools/list` ключам со
   scope коннектора. **Откат** — опубликовать прежнюю версию; **снять с публикации** — инструменты пропадают за ≤ 30 с.
8. **Ключу** добавить scope коннектора (экран ключа или заявки) — без этого клиент инструментов не увидит.
Пример: праздники РФ — `https://date.nager.at/api/v3`, вход «нет», инструмент `holidays_year`, путь
`/PublicHolidays/{year}/RU`, параметр `year` (в пути, целое), ответ — список, поля `date` → `/date`, `name` → `/localName`.

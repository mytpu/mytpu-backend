# Консоль: свой выпадающий список и читаемый журнал действий

Статус: черновик, ждёт «ок» владельца (2026-11-07).

## Проблема (сверено с кодом 2026-11-07)
1. **Журнал действий нечитаем.** `RagAdminProxy.send` пишет в `admin_audit` каждый не-GET запрос к rag, в том числе
   `POST /playground` — это чтение (поиск в песочнице), а не изменение. В `after` уходит весь ответ rag (до 16 КБ: 30 кандидатов).
   Консоль (`admin-audit.page.ts → parseDiff`) знает только `reason`/`mode`/`enabled`, иначе выводит `row.after` как есть —
   сырой JSON на весь экран. Ещё: ключи `mcp.adminAudit.action_*` есть не для всех действий (видно `mcp.adminAudit.action_rag_post`),
   фильтр периода не передаётся в запрос (всегда последние 24 ч), фильтр «тип» не знает `connector`, `key_request`, `rag`.
2. **Выпадающие списки.** 20 нативных `<select>` в 15 файлах, каждый со своими стилями; всплывающее меню рисует браузер
   (Windows: синяя подсветка, свой шрифт и рамка) — не совпадает ни со светлой «Оригами», ни с тёмной «Графит».

## Решение
### А. Шлюз — песочница не пишется в журнал
`RagAdminProxy`: `POST /playground` — чтение, в журнал не идёт (как GET). Остальные изменения rag пишутся как сейчас.
Тест: песочница — записи нет; `PUT /documents/{id}` — запись есть.

### Б. `ui/select` — общий выпадающий список
- `app-select`: `ControlValueAccessor` (работает и с `ngModel`, и с `formControlName`), входы `options: {value, label, hint?}[]`,
  `placeholder`, `icon`, `size: 'sm' | 'md'` (36 / 40 px), `disabled`.
- Кнопка — как поле консоли: `--bg-tile`, рамка `--border-tile`, радиус `--radius-button`, стрелка поворачивается при открытии,
  фокус — рамка `--green-action`.
- Меню — CDK Overlay (уже в зависимостях): плитка `--bg-tile`, рамка `--border-tile`, радиус `--radius-tile`, тень `--shadow-dialog`,
  ширина не меньше кнопки, до 320 px высоты с прокруткой. Пункт: наведение/активный — `--bg-nested`, выбранный — `--green-soft`,
  текст `--green-text` и галочка. Появление — `m-pop-in` (общие анимации), без `forwards`.
- Клавиатура: ↑/↓, Home/End, Enter/Space, Esc, Tab закрывает, ввод букв — переход к пункту. ARIA: `combobox` + `listbox`/`option`.
- Заменить все 20 нативных `<select>`; локальные стили селектов удалить.

### В. Журнал действий
- Колонка «Что изменилось»: одна строка-итог по-человечески по действию (например «Режим: обычный → строгий»,
  «Документ отключён», «Ключ отозван: причина …»). Сырой JSON в таблице не показывается никогда.
- Кнопка «Подробнее» раскрывает строку под записью: список «поле — было → стало» (вложенные поля через точку, значение
  обрезано до 200 символов, изменившиеся поля подсвечены, неизменные скрыты).
- Подписи для всех действий из шлюза (`mode.set`, `tool.*`, `integration.*`, `key.*`, `key_request.*`, `connector.*`, `rag.*`)
  и типов объектов; неизвестное действие — его код моноширинным, а не ключ перевода.
- Фильтр периода передаёт `from`; фильтр типа — `mode, tool, integration, key, key_request, connector, rag`.
- Фильтры — на `app-select`.

## Шаги
1. Шлюз: песочница вне журнала + тест (падает без правки).
2. `ui/select` + стили обеих тем.
3. Замена 20 `<select>`.
4. Журнал: итог, подробности, подписи, фильтры; демо-данные журнала (если есть) — примеры разных действий.
5. Проверка: `bash .claude/verify.sh` (gateway + `ng build` обе конфигурации), демо-режим в браузере — журнал и
   3–4 экрана с выпадающими списками в светлой и тёмной теме, клавиатура.

## Вне рамок
Старые записи песочницы в БД стенда остаются; в журнале они покажутся итогом «Запрос в песочнице rag» без JSON.

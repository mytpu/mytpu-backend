# Ключ только из РФ: приостановка при первом вызове из-за рубежа

Опирается на `specs/key-lifecycle-and-decoys` (2г: сроки, приостановка, `key_events`, оповещения `KeyAlerts`) и
`specs/mcp-key-and-agent-safety` (часть А: сети ключа, `McpKeyFilter`, `ClientAddress`). Идея владельца 2026-10-31.

## Зачем
Студенты и интеграции ТПУ работают из России. Вызов мастер-ключом из другой страны почти всегда значит, что ключ утёк.
Сейчас такой вызов проходит, если у ключа нет сетей (`person`) — о нём узнаём только по событию «новая подсеть». Нужно,
чтобы ключ с пометкой «только РФ» выключался на **первом же** вызове из-за рубежа, без нескольких попыток, с понятной
причиной и сообщением команде.

## Принципы
- **Страна — по локальной базе адресов**, без внешних запросов: адрес клиента никуда не уходит, ответ — за микросекунды.
- **Приостановка, а не отзыв**: студент с VPN — частый ложный случай; администратор снимает приостановку одной командой.
- **Облачные агенты — отдельно.** ChatGPT (коннекторы) и Claude в браузере вызывают MCP со своих серверов в США, а не
  с компьютера студента. Ключ для них выдаётся явно с политикой «любая страна»; личного по такому ключу и так нет
  (`personal-data-for-agents`). Claude Code и свои клиенты ходят с компьютера пользователя — им «только РФ» не мешает.
- Пороги, страны и путь к базе — в `application.yml`, не литералами.

## Критерии готовности (проверяемые)

**Страна адреса**
- [x] Шлюз определяет страну адреса клиента (IPv4 и IPv6) по локальному файлу базы (`mytpu.gateway.keys.geo.db-path`,
  том только для чтения); внешних запросов нет. Частные, loopback и link-local адреса — «своя сеть», не заграница.
- [x] `geo.enabled: true`, а файла нет или он не читается → шлюз не стартует с понятной ошибкой (как обязательный
  `ML_PROVIDER`). `geo.enabled: false` — проверка выключена, ключи «только РФ» работают как раньше, WARN при старте.
- [x] Адрес клиента — тот же, что для сетей ключа (`ClientAddress`: `X-Forwarded-For` только от доверенного прокси).

**Политика ключа**
- [x] У ключа есть политика `geo`: `ru_only` (разрешённые страны — `geo.allowed-countries`, по умолчанию `[RU]`) или `any`.
  Умолчание — по типу из настроек (ответ на вопрос 1); ключи консоли и ловушки — `any` (консоль закрыта сетями,
  ловушка срабатывает откуда угодно).
- [x] Политику задают: `issue-key --geo=ru|any`, консоль при выдаче (`POST /admin/api/keys`), смене прав
  (`PUT …/permissions`) и одобрении заявки; изменение пишет журнал действий. `any` для ключа `person` — только с
  причиной (поле `geoReason`, «облачный агент ChatGPT» и т. п.), она видна в списке ключей.

**Срабатывание**
- [x] Ключ `ru_only`, адрес из страны вне списка → в том же запросе: приостановка (`suspended_reason = 'foreign:<код
  страны>'`), событие `key.foreign_country` (страна, подсеть), оповещение (событие — в списке `alerts.events` по
  умолчанию); ответ — 401 `key_suspended`, как у любой приостановки. Второй попытки нет.
- [x] Страна не найдена в базе (публичный адрес) → вызов проходит, событие `key.geo_unknown` (не чаще раза в час на
  ключ) — ответ на вопрос 2.
- [x] Ловушка: проверка страны её не касается — ответ по-прежнему как у неверного ключа.
- [x] Снять: `issue-key --resume` / `POST /admin/api/keys/{id}/resume`; при снятии можно сразу сменить политику на `any`.

**Документы**
- [x] `docs/SECURITY.md` §14 — правило, ложные случаи (VPN, облачные агенты) и что сказать студенту; `deploy/README.md` —
  откуда взять файл базы, как обновлять (раз в месяц), том в `compose`; атрибуция базы, если её требует лицензия.
- [x] Спецификация консоли (часть Б): переключатель «Только из России» в мастере ключа и заявке, событие в ленте
  «События ключей».

## Не входит (non-goals)
- Определение VPN, прокси и хостингов по ASN; «подозрительные страны» с разными порогами.
- Свой список стран для каждого ключа — только общий `allowed-countries`.
- Автоснятие приостановки, временная блокировка «на час».
- Проверка страны для консоли (она закрыта сетями) и для анонимного трафика (его нет).
- Геопроверка в assistant и rag; гео-лимиты частоты.

## Ограничения
- Безопасность/данные: в событиях и оповещениях — страна и подсеть, без полного адреса; база адресов — файл, не в git;
  лицензия базы — совместима с коммерческим и учебным использованием (вопрос 3).
- Архитектура: всё в `access` (+ поля в `admin`); проверка страны — отдельный класс, `McpKeyFilter` только вызывает его
  (фильтр уже 158 строк); новых `*Manager` нет. Схема — одной миграцией (следующий свободный номер; шаг 7а части Б консоли
  тоже претендует на V7 — кто первый, тот V7).
- Память: база стран — файл MMDB ~8–10 МБ, читается через отображение в память (не в кучу gateway 380 МБ).
- Контент: тексты — `messages.properties`; страны, путь, умолчания — `application.yml`.

## Ответы на открытые вопросы (утверждено 2026-10-31)
1. Умолчание — `ru_only` у `person`, `server`, `demo`; `any` — только явно, с причиной.
2. Страна неизвестна — пропускать, событие `key.geo_unknown` (раз в час на ключ).
3. База — DB-IP «IP to Country Lite» (MMDB, CC BY 4.0, раз в месяц; проверено 31.10: файл 8 МБ,
   `https://download.db-ip.com/free/dbip-country-lite-YYYY-MM.mmdb.gz`), атрибуция «IP Geolocation by DB-IP».
4. Клиент видит обычный 401 `key_suspended`.

## Открытые вопросы (были)
1. **Умолчание по типу.** Рекомендация: `server`, `demo`, `person` — `ru_only`; `any` — только явно, с причиной (облачный
   агент). Минус: студент с VPN получит приостановку — в инструкции к ключу пишем «ключ работает только из России,
   выключите VPN». Альтернатива — `person` по умолчанию `any` (меньше ложных случаев, но тогда правило почти не защищает).
2. **Страна неизвестна** (адреса нет в базе): рекомендация — пропускать с событием `key.geo_unknown`; альтернатива —
   считать заграницей (строже, но новые блоки адресов российских операторов дадут ложные приостановки до обновления базы).
3. **Источник базы.** Рекомендация — DB-IP «IP to Country Lite» (MMDB, обновление раз в месяц, без регистрации, лицензия
   CC BY 4.0 — нужна строка атрибуции) `#непроверено` (проверить на шаге 1). Альтернативы: MaxMind GeoLite2 Country (точнее,
   нужна учётная запись и ключ лицензии для скачивания), выгрузки регистраторов RIPE/ARIN (страна регистрации, не
   местоположения — грубее).
4. **Что видит клиент.** Рекомендация — тот же 401 `key_suspended`, без слова «страна» (не подсказываем злоумышленнику
   правило); причину видит команда в событии и оповещении. Альтернатива — отдельный код `key_suspended_foreign`, понятнее
   студенту с VPN.
